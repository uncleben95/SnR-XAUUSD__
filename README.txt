XAU/USD PRO SCALP ENGINE V4
==============================

DESIGN
------
1. M5 is the PRIMARY execution timeframe.
2. A scalp signal is generated only after a CLOSED M5 candle crosses a CONFIRMED swing high/low.
3. M15 is used for confirmation and quality scoring.
4. H1 is a SWING CONTEXT REFERENCE ONLY.
5. H1 never blocks a scalp signal.
6. A BUY/SELL push is generated only when the scalp score reaches 85/100.
7. Push is generated by the backend, not by the browser tab.
8. Duplicate push is protected by a Redis signal key for 24 hours.
9. Retest is not required. The trigger is the closed M5 breakout candle.
10. TP levels prefer confirmed M5/M15 structure; fallback is minimum 1.5R.

WHY THREE CSVs WERE USED
------------------------
The supplied M5, M15 and H1 files were used to inspect the structure and to run a
descriptive historical test. The live engine also reads all three timeframes from
Twelve Data, with independent Redis caching.

IMPORTANT LIMITATION
--------------------
The supplied history does NOT prove that this engine will be profitable or
"accurate" in live trading. The historical test is not a guarantee and does not
include spread, slippage, commissions, latency, broker-specific fills or regime
changes. Treat the 85/100 score as a quality filter, not a probability.

LIVE DATA / FREE TWELVE DATA PLAN
---------------------------------
Background workflow runs every 5 minutes.

Approximate external Twelve Data requests:
- M5: fresh every 5 minutes -> ~288/day
- M15: cache 15 minutes -> ~96/day
- H1: cache 60 minutes -> ~24/day
- Total background external requests: ~408/day

Dashboard polls every 15 seconds, but it normally reads Redis-cached market data,
so it does not create a new Twelve Data request on every browser poll.

DEPLOYMENT CHECKS
-----------------
1. Open:
   /api/health

2. Open:
   /api/scalp

3. If /api/health is 200 but /api/scalp is 500:
   check Vercel environment variables.

4. If GitHub Actions gets 404:
   SCALP_API_URL points to the wrong deployment/domain, or the deployed project
   does not contain api/scalp.js.

5. If GitHub Actions gets 401:
   Vercel Deployment Protection is blocking the workflow.

6. After deployment, press ENABLE in the dashboard and then TEST.

SIGNAL LOGIC
------------
Scalp:
  M5 confirmed swing cross
  + M5 candle/body and trend quality
  + M15 EMA trend
  + M15 RSI
  + M15 MACD histogram
  + M15 ADX
  + M5 ATR expansion

Swing:
  H1 structure + H1 EMA20/EMA50
  -> shown only as hold context after/around a scalp entry.

The swing context can say ALIGNED, OPPOSED or NEUTRAL, but it cannot change
BUY/SELL into WAIT when the scalp engine has already reached ENTRY_READY.

NO AUTOMATIC TRADE EXECUTION
----------------------------
This repo generates signals and push notifications. It does not place broker
orders.
